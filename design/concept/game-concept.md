## 1. 游戏支柱（Design Pillars）

后续所有设计决策以这三条为裁判标准，任何新机制若与支柱冲突即砍或改。

| # | 支柱 | 一句阐释 |
|---|------|----------|
| P1 | **所见即所得** | 每次点击换装必须立即产生肉眼可见的角色变化——反馈延迟是换装游戏的第一死因，所有 UI/渲染决策为其让路（配合 D1-09 人物 180 度旋转与 D1-11 动效白名单）。 |
| P2 | **表达即玩法** | 搭配没有对错与标准答案，每一件单品的取舍都是玩家的自我表达——系统只提供画布与素材，永远不评判玩家的审美（按 D1-01 自由搭配为主重写阐释）。 |
| P3 | **轻量可持续** | 单次会话 3-8 分钟，单手竖屏可完成全部操作——随时进出、零压力回归（每日任务无倒计时无强评分，按 D1-03）。 |

**支柱裁判示例**：某候选机制若要求玩家阅读超过两行说明文字（违反 P1）、若引入"正确搭配"判定或排名比较（违反 P2）、若单次会话超过 10 分钟（违反 P3），直接否决。

## 2. MDA 框架分析（按 D1-01 自由搭配为主重写）

### 2.1 机制层（Mechanics）
- **分层纸娃娃系统**：角色由 13 槽位（D1-10）分层叠加渲染，槽位互斥、层内换装，点选即换、所见即所得（P1）。
- **人物 180 度旋转**（D1-09）：自由查看正面/背面，连衣裙背部蝴蝶结、披风内衬等"背面细节"成为单品卖点与搭配乐趣的一部分。
- **风格标签**：每件单品携带 1-3 个风格标签（如"星夜""宫廷""糖果"）——v0.2 中标签职责降级为**衣柜筛选与图鉴分类**，不再作为评分依据（评分已弱化，D1-01）。
- **自由搭配台**：主界面即画布，无倒计时、无评分入口，试穿、旋转、保存造型全部即时完成。
- **轻量每日任务**（D1-03）：每日 2-3 个软任务（如"今天试穿 3 件新单品""保存 1 个造型"），无倒计时、无强评分，完成给小额奖励。
- **双轨获取**（D1-04）：商店直购（货币购买）+ 成就解锁（行为达成直接给单品/家具），不设掉落、不设抽卡（D1-13）。
- **房间装饰**（D1-05 进 v1，D2-03/04 深度与视角已定）：第二个表达画布，锚点网格摆放、2D 固定正面视角。

### 2.2 动态层（Dynamics）
- 玩家在衣柜网格中翻找、对比、试穿——试穿即时可见（P1），**试穿本身就是玩法本体**，尝试零成本、零惩罚。
- 旋转（D1-09）让"正面好看"升级为"全身都好看"，玩家会主动追求正背面都成立的设计，形成深度摆弄。
- 每日任务不指挥玩家"搭什么"，只轻推"今天摸一摸游戏"（P3），完成后玩家回到自由摆弄——任务是从属，不是主菜。
- 商店直购 + 成就解锁（D1-04）把收集欲变成**可预期、可规划**的追求（攒币→目标单品），而非赌博式刺激——契合未成年向合规（D1-02）。

### 2.3 美学层（Aesthetics）
- **表达（Expression）**：核心愉悦——"这个角色、这个房间都是我一手布置出来的"（换装 + 房间双画布，D1-05）。
- **完成（Completion）**：图鉴收集完成、成就达成、房间逐渐被填满的建设感。
- **幻想（Fantasy）**：梦幻童话世界的理想化自我扮演（D1-07）。

### 2.4 心流与审美愉悦的产生路径
```
点选单品 → 即时视觉反馈 + 旋转端详（微满足，可无限循环）
   ↑                ↓
  再试一件    "我想要一套星夜礼裙" ← 玩家自发设立的表达目标
                     ↓
        攒币 / 做每日任务 / 跳成就 → 得到目标素材 → 表达空间扩大
```
心流锚点从 v0.1 的"外压挑战"改为**内驱目标**：挑战不再是系统出题，而是玩家给自己出的题；成就感来自"离我脑中的画面更近了"，而非"我赢了评分"。审美愉悦由摆弄过程本身与保存造型时的"作品感"承载。

## 3. 目标玩家画像（按 D1-02 修订：12-16 岁女性）

### 3.1 Bartle 类型侧重
| 类型 | 权重 | 落点 |
|------|------|------|
| 成就者（Achiever） | ★★★ | 图鉴收集 / 成就解锁清单 / 每日任务连签 |
| 探索者（Explorer） | ★★★★★ | 风格组合空间 / 旋转端详正背面 / 房间布置尝试 |
| 社交者（Socializer） | ✗ v1 不服务 | D1-06：v1 纯单机、无分享，关联感由"角色与房间是自己的小世界"间接承载 |
| 杀手者（Killer） | ✗ 明确不服务 | 无对抗、无排位（D1-13），保护未成年表达氛围 |

### 3.2 自我决定论（SDT）落点
- **自主（Autonomy）**：玩法即表达（P2）——没有评分、没有任务指挥"该搭什么"，自由搭配台完全由玩家做主。
- **胜任（Competence）**：从"赢分数"改为"建设感"——衣柜变满、图鉴点亮、房间从空到满、成就清单逐项划掉，胜任感来自可见的积累。
- **关联（Relatedness）**：v1 不做分享（D1-06），以"角色是我照顾的小世界伙伴"（呼吸/眨眼/裙摆常驻动效，D1-11）提供拟社会关联的替代满足。

### 3.3 未成年向合规 implications（D1-02 商业化克制）
- **无抽卡、无付费随机**（D1-13 已定），获取全走确定性的商店直购与成就解锁——规避未成年付费随机监管红线。
- **无排行榜/对抗**：避免比较焦虑，符合未成年人网络保护导向。
- **无强肝机制**：无倒计时任务、无连续登录惩罚曲线，单局 3-8 分钟（P3），不设计成瘾性循环。
- 商业化形态已定：**v1 完全免费、无内购**（D2-06），付费决策不阻塞切片开发；跨入商业化阶段需另行立项评审。

**画像一句话**：12-16 岁女性玩家，期望一个"随时打开、摆弄几分钟、越摆弄越丰富"的梦幻童话换装小世界——把游戏当创作工具而非竞技场。

## 4. 核心循环（按 D1-01 / D1-03 / D1-04 重写）

### 一句话版本
**打开我的小世界 → 自由试穿、旋转端详、保存造型 → 做轻量每日任务攒币 → 商店直购与成就解锁扩充素材 → 表达空间更大 → 继续摆弄布置。**

### 30 秒展开版本
1. **玩家做什么**：打开 App 进入自由搭配台，无倒计时无评分，从衣柜点选试穿（所见即所得），旋转看正背面（D1-09），满意则保存造型；顺手扫一眼每日任务（如"试穿 3 件新单品"），做不做都行（做什么）。
2. **得到什么**：造型被保存进"我的造型"收藏；每日任务给小额货币；达成成就（如"集齐星夜系列"）直接解锁新单品或家具（得到什么）。
3. **为什么再来**：商店一次性全量上架（D3-03，静态目录），回访拉力以**每日任务 / 成就解锁 / 收集进度**为主——攒币够买目标单品 + 成就清单的下一项悬而未决 + 房间还空着一角——"我的小世界还没长成我脑中的样子"，建设感驱动回归（为什么再来）。

> 货币来源设计（D1-04 双轨下不依赖高分）：每日任务奖励为主源、图鉴/收集进度奖励为次源、成就解锁直接给物品不绕货币。具体数值留待 Phase 2 经济 GDD。

## 5. 范围分层（Scope Layers）

### 5.1 核心范围（垂直切片必含）
- **1 个可换装女性角色**（D1-12），13 槽位纸娃娃分层渲染（D1-10），**含 180 度旋转正/背双视图**（D1-09）。
- **衣柜系统**：服装单品约 40-50 件（×正/背双视图 ≈ 80-100 张分层图，美术量核算见下），网格浏览 + 风格标签筛选 + 点选试穿。
- **自由搭配台 + 造型保存**：主界面即画布，**9 个造型收藏位**（D3-02，用户自定义值，超出原 3-5 位区间；不做扩容内购，D2-06）。
- **房间装饰系统**（D1-05 进 v1；深度与视角已拍板定稿）：
  - **定位**：第二核心玩法画布，但深度一档——**换装为第一核心，房间为"同构的第二个表达空间"**（同一套"浏览→点选→即时可见"交互，复用衣柜 UI 范式，开发与学习成本双低）。
  - **定稿口径**（D2-03）：约 30 件家具 + 1 个房间场景，**锚点网格摆放**（吸附预设点位，无自由拖拽、无旋转、无层叠），房间整体随摆放进度点亮氛围光。
  - **视角口径**（D2-04）：2D 固定正面视角 + 地面 Y 排序，720×1280 单屏不滚动。
  - 深化方向（自由拖拽/多房间/层叠）属 v1.1 及以后候选，不再留在 v1 讨论范围内。
- **轻量每日任务**（D1-03）：无倒计时、无强评分、小额奖励，任务池 ≥10 项轮换。
- **1 种货币 + 商店 + 成就双轨**（D1-04）：商店直购 + 成就解锁清单。
- **核心 HUD**：竖屏主界面（角色台 + 底部抽屉衣柜/家具切换）+ 造型保存页 + 商店/成就页。
- **触屏输入全套**：点选、滑动浏览、旋转按钮（单手可完成）。
- **美术量再核算（双资产线 + 双视图，量级已由 D2-01/02 定稿）**：服装 40-50 件（D2-02）×13 槽位分布 ×正背双视图（D2-01 全量双视图：13 槽全出正/背两套图，背面 60% 精度、HAIR_B/翅膀 100%，懒加载控内存）≈ 80-100 张分层图；家具约 30 件（D2-03）单视图；常驻动效仅呼吸/眨眼/裙摆 3 项（D1-11）控帧数。建议服装量级取下限起步、v1.1 补量。

### 5.2 加分范围（v1.1 候选，按优先级排序）
1. 换色系统（同款式不同色，低成本扩表达空间）
2. 限时节日主题单品（童话历法：星祭 / 雪之圆舞曲等）
3. 第二房间场景 / 房间深化（自由拖拽版为 v1.1 候选，v1 已按 D2-03 锚点版定稿）
4. 每日签到与收集里程碑曲线
5. 第二角色（视用户对 D1-12 的 v1.1 延伸意愿）
6. 造型收藏位扩容 / 造型相册

（v0.1 列首的"分享卡片/好友投票"已移除：D1-06 明确 v1 纯单机不做分享。）

### 5.3 可砍范围（明确不做，防蔓延，按 D1-13）
- ❌ 任何形式的实时多人 / 排行榜竞技（违背画像"不服务杀手者"）
- ❌ 剧情战役 / 大段文本叙事（违背 P1 轻量）
- ❌ 3D 渲染、物理布料（违背技术约束与 P1 性能）
- ❌ 抽卡 / 保底池 / 任何付费随机（D1-13，未成年向红线）
- ❌ 账号体系 / 云存档（v1 用 localStorage，Phase 5 复评丢档风险，D1-13）
- ❌ v1 内分享 / 好友互动（D1-06，纯单机体验）
- （v0.1 的"❌ 家具/房屋装饰"砍除项已删除：被 D1-05 推翻，房间装饰进 v1 核心范围。）

## 6. 视觉锚点（按 D1-07「梦幻童话 × 幻想系 · 美术方向 B」重写）

> 结构性硬约束不变：分层出图（每槽位独立透明 PNG、边缘无粘连）、竖屏 9:16 构图、**3.5 头身**（D1-08）、双视图资产规格（D1-09 + D2-01 全量双视图、背面 60% 精度、懒加载）。世界观载体已定稿：**星夜魔法学院**（D2-05）。

- **题材情绪**：一本被施了魔法的换装绘本——"星夜魔法学院里、拥有一衣柜星光的少女"。情绪基调是**憧憬与梦境感**，而非 v0.1 的日常治愈。单品系列与房间主题的命名脉络统一挂靠学院意象（星象课礼裙 / 魔药室围裙 / 图书馆披风 / 星象仪 / 月光书桌……），房间场景按 D2-05 校准为学院向（美术关键词已由「星语树屋/云朵小筑」更新）。
- **色调倾向**（美术方向 B）：**高明度渐变**为主——月光白 / 星夜蓝 / 薰衣草紫 / 玫瑰粉 / 香槟金；服装主色块用两段式渐变，避免大面积纯色与重阴影。
- **风格关键词（5 个）**：
  1. **梦幻渐变**——服装用高明度双段渐变塑造体积，阴影用紫灰色替代黑，整体像糖霜与月光。
  2. **光效点缀**——星光、珍珠、鎏金描边等光效**只用于配饰与高稀有单品**（既是视觉奖励层级，也控制同屏光效数量以保 Canvas 帧率）。
  3. **童话廓形**——大裙摆、泡泡袖、蝴蝶结、披风等强识别廓形优先，轮廓剪影即可读出"这是童话"。
  4. **贴纸感 UI**——按钮、货币、任务卡走圆润星尘贴纸质感，与服装渐变的"布料感"拉开层次。
  5. **性能护栏**——渐变与光效会显著增大文件体积与纹理内存（高 DPR 设备尤甚），护栏建议：渐变色板全局复用（不超过 ~20 组渐变定义）、光效用少量帧序列或 shader 参数化而非逐帧大图、单图长边像素上限与整包纹理预算由美术圣经 CAL 条目定死并与程基岩核对（Phase 3）。
