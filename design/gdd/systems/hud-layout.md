## 1. 概述

竖屏 9:16 单屏主界面：顶部导航（标题 + 货币栏 + 任务入口）、中部舞台区（换装角色台 ⇄ 房间舞台复用同一容器）、底部抽屉（衣柜 ⇄ 家具复用同一容器）+ 底部标签栏四入口。全 App 唯一主界面，无二级页面树——商店/成就/每日任务以**覆盖层页**形式挂载在主界面之上。

## 2. 机制

### 2.1 布局规格（720 逻辑宽基准，实际按 §3.2 换算规则缩放；引美术圣经 §6.1 栅格）

```
┌────────────────────────────┐
│ 状态栏区（安全区，动态高）      │ ← 刘海/挖孔避让
├────────────────────────────┤
│ 顶部导航  高 88               │ ← 左：当前模式标题(H1 44px)
│  ·货币栏 ·任务入口 ·造型入口    │    右：功能入口组(每项 ≥44×44)
├────────────────────────────┤
│                            │
│  舞台区（模式内容）            │ ← 换装=角色台(挂 S01)
│  换装: 角色台+旋转手势区       │    房间=房间舞台(挂 S07)
│  (默认档 55%，抽屉上拉时 30%) │
│                            │
├────────────────────────────┤
│  底部抽屉（模式内容）          │ ← 换装=衣柜抽屉(挂 S03)
│  (默认档 45%，上拉档 70%)     │    房间=家具抽屉(挂 S07)
├────────────────────────────┤
│  底部标签栏 高 96 + 安全区     │
└────────────────────────────┘
```

- 12 列栅格、列间距 16px、页面左右边距 24px（美术圣经 §6.1）。
- 抽屉两档位 45%/70%、上拉手势速度吸附阈值 0.5px/ms——口径已在 wardrobe-tryon.md §4 冻结，本册只提供容器、不重定义。

### 2.2 底部标签栏入口清单（本册定稿，主理人授权）

| # | 入口 | 图标语义 | 目标模式 |
|---|------|---------|----------|
| 1 | **换装** | 着裙小人 | `mode=dress`（默认模式） |
| 2 | **房间** | 小屋轮廓 | `mode=room` |
| 3 | **商店** | 星尘钱袋 | 覆盖层页（S08 挂载） |
| 4 | **成就** | 徽章 | 覆盖层页（S10 挂载） |

- **4 入口定稿理由**：美术圣经 §6.1 允许 4~5 个；「衣橱」不设独立入口（衣柜抽屉已内嵌于换装模式，避免入口与抽屉职能重复）；「每日任务」不放标签栏（见 2.3），保住 12-16 岁低认知负担（美术圣经 §9.6）。
- 图标按 §6.3 规范（4px 描边 + 圆角 12 + 单色填充，选中态星紫 `#8268C6` 填充 + 星/翼角饰仅限选中态）；4 入口间距均分，触控目标 ≥ 44×44（实际按钮区 ≥ 110×96）。

### 2.3 顶部导航功能入口组（从右至左；v1.1 同步增补音频开关行）

| 入口 | 形态 | 职责 |
|------|------|------|
| **音频开关**（v1.1） | 小喇叭二态按钮（开：喇叭+星尘音符；关：喇叭+柔和斜杠——图形双通道 V4） | 切换 `settings.audioEnabled`（audio-plan §7，ADR-002 settings 补丁落档），即时生效 mute/恢复；切换反馈与规格归 ux-spec.md §7 |
| **造型** | 相机/收藏图标按钮 | 打开 S06 造型面板（覆盖层） |
| **任务** | 信封图标 + 未读角标 | 打开 S09 每日任务覆盖层页；未完成任务数角标 |
| **货币栏** | 货币 icon + 等宽数字（tabular-nums，§3.2） | 只读展示 S04.coins；点按跳转商店覆盖层 |

- 任务入口放顶部而非标签栏的理由：每日任务是**软引导**（D1-03 从属地位），视觉权重应低于四大模式/功能入口，角标做轻提醒即可。

### 2.4 模式切换状态机（换装 ⇄ 房间）

```
[dress] ──点按房间标签──→ [switching ≤300ms 交叉淡切] ──→ [room]
   ←──────────── 点按换装标签，同路径对称 ────────────────
[shop/achieve] = 覆盖层页，不改变底层 mode（关闭即回到原模式）
```

- `mode ∈ {dress, room}` 二值；商店/成就为覆盖层，**不占模式位**。
- 切换 = 舞台区与底部抽屉**同时**换内容（角色台+衣柜抽屉 ⇄ 房间舞台+家具抽屉），舞台交叉淡切 ≤300ms、可被下一次点按打断（与 S01 动效同规则）。
- 每次进入模式时抽屉重置为默认档 45%（状态不跨模式记忆——单手拇指热区一致性优先）。

### 2.5 职责边界（容器红线）

- 本册管：布局栅格、舞台/抽屉容器挂载点、模式切换与过渡、入口与角标、安全区避让。
- 本册不管：衣柜网格与试穿（S03）、家具抽屉内部（S07）、商店/成就/任务页内容（S08/S09/S10）、造型面板内容（S06）、角色渲染与旋转（S01）——各覆盖层与抽屉内容物**只依赖本册提供的挂载接口（§6）**，不得反向改写容器布局。

## 4. 公式

- **舞台/抽屉档位**：`舞台高 = 屏高 − 状态栏 − 顶导88 − 标签栏96 − 安全区`；抽屉默认档 = 舞台剩余 × 45%、上拉档 70%（口径承 wardrobe-tryon.md §4，两模式通用）。
- **模式切换过渡**：交叉淡切 T ≤ 300ms（美术圣经 §8 单次反馈上限）；打断规则：新点按到达即中止当前过渡、目标态直接落定。
- **字号换算**：`渲染字号 = 设计值 × (实际屏宽 / 720)`（美术圣经 §3.2），最小可读 12 独立像素下限不破。
- **角标规则**：`显示角标 ⇔ 计数 > 0`；角标数字 > 9 显示"9+"；角标只用语义色 + 图标差异承载（不裸用红色制造紧迫感，美术圣经 §9.6 商业化克制条款）。

## 5. 边缘情况（≥3 类）

1. **竖屏锁定**：手机竖屏优先（D0），检测横屏 → 全屏遮罩提示"请旋转回竖屏"，不提供横屏适配（v1 砍除项口径）；桌面浏览器调试窗口同理提示。
2. **异形屏安全区**：刘海/挖孔/手势条高度运行时读取，顶导与标签栏分别下探/上探避让；舞台内容锚定栅格中轴，不受安全区挤压形变。
3. **切换中快速往返**：dress→room 过渡未完即点回换装 → 中止过渡、直接落定 dress（无过渡队列）；连续多点按防抖 100ms 窗口（同一点按源）。
4. **覆盖层与模式互斥**：商店/成就/任务/造型覆盖层打开时，标签栏与顶部入口不可点（覆盖层遮罩吸收触控）；同一时刻**仅允许一层覆盖**（覆盖层内不开覆盖层——S08 商店详情等一律用页内内嵌展开，不叠层）。
5. **角标数据滞后**：角标由事件回调驱动，覆盖层打开期间任务完成/成就达成 → 关闭覆盖层时强制刷新一次角标（以 S04 读数为准，容忍 ≤1 帧滞后，不阻塞交互）。
6. **首启默认态**：无档新用户进入 `mode=dress`、抽屉默认档、角标按 S09 当日任务初始化。
7. **极小/极长屏幕**：9:16 基准外（如 20:9 长屏）——舞台区随屏高增益（角色台留白增多）、抽屉档位按百分比公式自适应，栅格中轴不变；不设最大屏高截断。

## 6. UI 接口（供各系统挂载）

| 接口 | 语义 | 消费方 |
|---|---|---|
| `getStage(mode)` | 返回舞台区渲染容器（换装模式由 S01 挂角色画布，房间模式由 S07 挂房间画布） | S01、S07 |
| `getDrawer(mode)` | 返回底部抽屉容器（衣柜挂 S03，家具抽屉挂 S07） | S03、S07 |
| `openOverlay(page)` / `closeOverlay()` | 覆盖层唯一开关（互斥单层，§5.4）；返回页实例容器 | S06/S08/S09/S10 |
| `onModeChange(cb)` | 模式切换完成事件（S03 据此重建/挂起抽屉内容、S07 据此恢复房间舞台） | S03、S07 |
| `setCurrencyDisplay(coins)` | 货币栏刷新（S04 余额变更事件 → 本册镜像显示） | S08/S09 触发刷新 |
| `setBadge(target, count)` | 任务/成就角标写入（target 枚举：`task/achievement`） | S09、S10 |

## 7. 依赖

- **被依赖**：S01（舞台容器）、S03（抽屉容器与模式事件）、S06/S08/S09/S10（覆盖层挂载与角标）、S07（房间舞台与家具抽屉）——systems-index 依赖图口径。
- **依赖**：S04（coins 镜像、任务/成就进度计数来源）；美术资产：底部标签栏 4 图标 + 顶部 3 图标 + 货币 icon（美术圣经附录 B P0 UI 项）。
- **无程基岩阻塞项**：布局量级为静态 DOM/Sprite 层级，无特殊渲染风险；交叉淡切进美术圣经 §8 反馈动效家族（≤300ms 合规）。

## 8. 验收标准

1. 720 逻辑宽栅格全对齐（12 列 / 16px 列距 / 24px 边距 / 顶导 88 / 标签栏 96），实际渲染按 §4 换算无漂移。
2. 四标签 + 三顶部入口触控目标全部 ≥ 44×44、间距 ≥ 8px；核心操作全部落于下半屏拇指热区（美术圣经 §9.3 单手可达）。
3. dress⇄room 切换 ≤300ms、可打断、无过渡队列；进入模式抽屉重置默认档。
4. 覆盖层互斥单层；打开期间底层入口不可误触。
5. 货币栏与 S04.coins 一致（含 S09 发奖后即时刷新）；角标 >0 才显示、>9 显示"9+"、无紧迫感红光（§9.6）。
6. 异形屏安全区避让正确（顶导不被刘海遮挡、标签栏不被手势条遮挡）。
7. 文本对比度全项过 §9.1（夜墨 vs 雾光底 10.5:1 等已校验色对）；图标语义色弱可辨（§9.2）。
8. 职责边界代码评审通过：无系统改写容器布局、无容器侵入页内交互（§2.5 红线）。
