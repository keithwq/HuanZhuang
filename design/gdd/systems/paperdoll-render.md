## 1. 概述

角色画面 = 13 槽位分层贴图按固定 z 序叠加合成；支持**正/背双视图即时切换**（D1-09，纯 2D 管线下"180° 旋转"即双视图切换 + 过渡动效，美术圣经 §4.5 方案 a，D2-01 全量双视图）。本册定义：层序规则、槽位互斥与连衣裙逻辑、旋转交互（拖拽 + 显式按钮双路径）、锚线对位、懒加载与内存口径、动效参数。

**红线**：换装反馈与旋转过渡均 ≤300ms（D1-11，美术圣经 §8）；稳态纹理内存 ≤45MB、切换瞬时峰值 ≤75MB（美术圣经 §5.5，CAL-04 转程基岩核对）。

## 2. 机制

### 2.1 分层合成
- 13 槽位（D1-10）正/背两套独立层序表，**正面层序按美术圣经 §4.3（L00 BK → L12 FX），背面层序按 §4.5 背视图表（B-L00 HAIR_F → B-L11 FX，FACE 背视图不渲染）**。
- 每槽位同时最多 1 件（HAND 槽左右手挂点各 1 件，美术圣经 §4.3 规则）；槽位内渲染顺序固定，禁止依赖打破全局层序。
- 画布：512×1024 逻辑像素，画布坐标即世界坐标（美术圣经 §5.1），垂直中轴 x=256。

### 2.2 正/背双视图切换（S02）
- **触发路径双轨**（美术圣经 §6.1/§9.3，触控冗余）：
  - 路径 A（手势）：角色展示区**横向拖拽**触发翻转，拖拽目标区 ≥ 全宽 × 96px 高；
  - 路径 B（按钮）：造型台显式「转身」按钮，等价点按路径。
- **过渡动效**（美术圣经 §8.1）：3 帧转身剪影过渡，角色水平压缩至 8% 再展开，**≤300ms**，期间完成纹理换装；减敏模式（§9.4，跟随系统 `prefers-reduced-motion`）降级为 100ms 纯淡切，禁用压缩转身。
- **懒加载**（D2-01）：默认常驻当前视图纹理；翻转触发时 300ms 过渡窗口内预载目标视图纹理、完成后卸载旧视图纹理。稳态内存 ≈ 单视图水平（≤45MB），瞬时峰值 ≤75MB。

### 2.3 槽位互斥与连衣裙
- 试穿 TOP 类连衣裙：渲染层隐藏 BTM 槽已选资产（**保留 BTM 选择状态**，美术圣经 §4.3 连衣裙规则）。
- 每次换装 = 单槽位单事件（点选即换，无确认步骤），触发换装确认动效（美术圣经 §8.1：旧件 100ms 淡出 → 新件 150ms 淡入 + 2% 上浮落定）。
- BODY 为不可卸载遮蔽层（美术圣经 §4.3 L01）：任何槽位为空时显露 BODY 基础内衣形态。

### 2.4 常驻微动效（D1-11 白名单，仅 3 项）
呼吸（躯干 ±1% 缩放，3s 周期）、眨眼（8s 周期 ±2s 随机，闭眼 120ms）、裙摆/发梢微风（±2px 水平摆动，4s 周期）——参数即美术圣经 §8.2，白名单外循环动效一律拒绝。

### 2.5 「套装完成」判定与事件（v1.1 新增 · audio-plan §8.1-1 中转闭环）

**判据**：某系列静态清单（economy-acquire §3 物品表 `{seriesId, 成员清单}`，判据只读）**全部成员在 13 槽 outfit 状态中同时上身**——**目录完成口径**（"全部成员"指系列清单全集，非"已拥有件全集"）。

**边界口径**：
- **未拥有不触发**：系列 5 件玩家只拥有 3 件、穿齐 3 件 → 不触发（未拥有件不可能上身，目录完成天然不可达）——庆祝时刻保持稀缺：套装完成光晕与限定/稀有的浮动色位资产（美术圣经 §2.3）同属"仪式感正反馈"层级，owned-complete 口径会在购置途中反复触发、使光晕廉价化；
- **连衣裙占位看状态不看渲染**：系列含 TOP 连衣裙 + 配套 BTM 时，连衣裙穿着期间 BTM 件在槽（被遮蔽、状态保留，§2.3）即算上身——与 look-save §2.2 快照"含被遮蔽 BTM"语义完全同源；
- **HAND 系列件分左右手槽登记**，两槽各就其件；HAIR 成对件穿上即两槽同时就位（§2.1）；
- **混搭不触发**：跨系列组合不产生任何套装事件。

**触发时机与事件语义**：每次成功 `tryOn`（含 unequip 后的重新 tryOn）与批量回穿落位后，惰性判定**仅受影响系列**（本次换入件所属 seriesId）：
- 状态跃迁 **未集齐 → 集齐** 时发射 `onSeriesComplete(seriesId)` **一次**；
- 已集齐状态下继续换装（维持集齐）**不重复发射**；卸下/换走解除集齐**无负事件、无取消动效**（庆祝是授予，不是可撤销的状态）；
- **批量回穿（applyLook）**：静默落位后统一判定一次；多系列同时跃迁集齐时**只发射部件数最多的一个**（防多光晕/多音效连播，与 look-save §2.5 防 13 连播同原则）；
- 重复触发合规性：每次发射均为美术圣经 §8.1 单次光晕呼吸 + ≤12 粒粒子（单次、非循环，M1 光敏安全）。

**消费方**：美术圣经 §8.1「套装完成」光晕动效（本节为其唯一发射源）；音频方案 S2 套装完成音（docs/audio/audio-plan.md，bus 事件名提案 `outfit:setComplete`，经主理人与程基岩对齐后落位）。

## 4. 公式

- **转身压缩动效**：`scaleX(t) = max( |cos(π · t / T)| , 0.08 )`，T ≤ 300ms；t = T/2 时完成纹理换装（剪影最窄处）。减敏模式：直接 100ms 交叉淡切。
- **换装确认**：旧件淡出 100ms → 新件淡入 150ms + 落定上浮 2%（总 ≤300ms，全程可打断——新事件到达即中止当前动效立即进新状态）。
- **纹理内存估算**：`单部件内存 ≈ 逻辑宽 × 逻辑高 × DPR² × 4B`；DPR=3 设备策略待程基岩核对（CAL-04）。
- **懒加载预算校验**：`稳态 = 当前视图全 13 槽贴图 + BODY 双视图基底 + UI 底图 ≤ 45MB`；`峰值 = 稳态 + 目标视图全槽贴图 ≤ 75MB`（300ms 窗口内短时共存，美术圣经 §5.5）。
- **动效帧率**：所有动效按 60fps 设计；低端机掉帧至 30fps 时动效时长不变、帧数减半（动效容忍、合成不降级）。

## 5. 边缘情况（≥3 类）

1. **连衣裙 ⇄ 分体切换**：连衣裙 → 分体上装：BTM 自动恢复显示（状态从未丢失）；连衣裙穿着期间玩家在衣柜给 BTM 换装：允许（状态更新、画面仍遮蔽），回到分体时生效——**状态与渲染解耦**。
2. **HAIR 前后层强制成对**：发型选择 = 同时设定 HAIR_B + HAIR_F 同前缀两件（美术圣经 §5.3）；不存在"只换刘海不换后层"操作，接口层拒绝跨发型的 HAIR_B/HAIR_F 混搭组合（返回错误而非渲染穿帮）。
3. **背面纹理未就绪时旋转**：懒加载目标纹理在 300ms 过渡内未完成——剪影过渡照常启动，纹理迟到则以"旧视图淡切到新视图"补完，**宁可晚到 100~200ms 也不出现空槽/白体**；同视图连续旋转请求在过渡进行中一律忽略（无旋转队列）。
4. **BACK 视图特殊槽**：FACE 槽在背视图不渲染（美术圣经 §4.5）；BK 翅膀/光环在背视图处于最近端（B-L10），与正面（L00 最远端）层序镜像——两套层序表独立维护，禁止用一张表加翻转逻辑推导。
5. **首启无存档**：S04 无档时按内置默认套装渲染（初学者初始装扮）；有档读档。存档含已下架/未来版本物品时按 itemId 缺图兜底：该槽回退默认件 + 控制台警告（v1 无删除物品计划，此为防御性设计）。
6. **旋转手势与衣柜滚动冲突**：拖拽区（全宽×96px）与底部衣柜抽屉无重叠（美术圣经 §6.1 布局分区），手势判定以触发起点区域为准，跨界滑动不触发翻转。
7. **减敏 + 旋转**：`prefers-reduced-motion` 下 100ms 淡切（美术圣经 §9.4），且不预载剪影 3 帧动画资产。

## 7. 依赖

- **被依赖**：S03（tryOn/unequip）、S05（舞台容器）、S06（快照/回穿）——systems-index 依赖图口径。
- **依赖**：美术 BODY 基底（正/背两张，先定稿冻结，美术圣经 §5.3/附录 B P0 骨架）；S04 存档（初始装扮读取：有档读档、无档默认）；旋转过渡剪影 3 帧（附录 B P0）。
- **跨团队**：CAL-04 内存预算与 DPR=3 策略待程基岩 Phase 3 核对；本册 §4 公式为设计口径，最终以核对结论修正。

## 8. 验收标准

1. 全 13 槽 × 正/背双视图资产按 §4.4 命名规范入库，锚线对位通过美术圣经 §5.1 基准网格校验图比对（偏差 ≤ 2px）。
2. 点选试穿 → 画面变化全程 ≤300ms；旋转过渡 ≤300ms；动效均可被下一操作打断（无卡死态）。
3. 混搭测试：≥20 组随机跨槽组合，正/背双视图均无穿帮、无露底、无层序错误（方案 a 承诺，美术圣经 §4.5）。
4. 稳态纹理内存 ≤45MB，旋转瞬时峰值 ≤75MB（CAL-04 核对后以最终口径复测）。
5. 拖拽与「转身」按钮双路径均可达翻转（触控冗余，美术圣经 §9.3）；减敏模式下动效合规（§9.4）。
6. 常驻动效仅呼吸/眨眼/裙摆 3 项（D1-11），无白名单外循环动效。
7. 60fps 目标帧率下合成与动效无可感知卡顿；低端机 30fps 动效降级不破坏体验。
