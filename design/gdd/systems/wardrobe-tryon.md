## 1. 概述

底部抽屉式衣柜：13 槽位页签 × 拥有物网格 × 风格标签筛选 × 点选即换。**没有确认按钮、没有评分、没有"应用搭配"步骤**（D1-01）——点选卡片的那一下就是玩法的全部。缩略图统一用正面视图；当前视图为背面时试穿同步刷新背视图渲染（经 S01 接口）。

## 2. 机制

### 2.1 界面结构（引美术圣经 §6.1 布局栅格）
- **底部抽屉两档**：默认档高 45%（角色台 55%），上拉档 70%（角色台压缩至 30%，仅保留头部以上可视）；下拉回默认档。抽屉把手拖拽区全宽、高 96px。
- **分组页签（GAP-4 闭环修订）**：抽屉顶部横向页签条 = **8 分组页签**（G1 发型 / G2 头饰 / G3 上装 / G4 下装 / G5 外套 / G6 鞋袜 / G7 配饰 / G8 光效——13 槽位→8 组，达可访问性矩阵 C3「≤8 组」上限；**分组表、组内次序与混组规则以 ux-spec.md §2 为准**）；**横向滑动切换页签，并提供等价点按路径**（触控冗余，§9.3）。换装仍逐槽互斥（组概念不进渲染层）；发型组选中即同时操作 HAIR_B+HAIR_F（见 §5.2），BODY 不入页签（美术圣经 §4.3 L01）。`onTabChange` 参数由槽位代码收窄为组 ID（语义不变，ux-spec §2.3 注记）。
- **物品网格**：卡片 104×104（§6.2），4 列布局；卡片 = 正面缩略图 + 角标态（当前穿着/系列标记，角标差异承载状态、不靠纯色，§9.2）。
- **筛选条**：页签条上方风格标签 chips，单选 + "全部"（v1 口径：标签职责已降级为筛选与图鉴分类，D1-01）。标签全集以静态配置表维护，控制在 8 组以内（§9.6 认知负担上限）。
- **卸下按钮（GAP-4 随分组修订）**：网格区首位固定「卸下」卡片——**混组为每槽一张卸下卡并以 Caption 标注槽位**（G2 头饰×2 / G7 配饰×3 / G8 光效×2，细则见 ux-spec.md §2.1 分组表）；单槽组口径不变：卸下 = 槽位回空、BODY 显露——显式按钮路径满足美术圣经 §9.3「撤销换装保留显式按钮」，不依赖手势。

### 2.2 点选即换状态机（P1 红线）

```
[浏览态 idle]
   │ 点选卡片（含"卸下"卡）
   ├─ 卡片未拥有 → 不可达（衣柜只显示已拥有，见 §5.1）
   ├─ 卡片 = 当前穿着 → 轻反馈（卡片微缩放 100ms），无状态变化
   └─ 其他 → [试穿态 trying]
              │ 调 S01.tryOn(slot, itemId)（或 unequip）
              │ S01 播放换装确认动效（≤300ms，美术圣经 §8.1）
              │ bumpStat('tryOnTotal')；首穿该件另计 tryOnUnique（S09/S10 判据）
              └→ [浏览态 idle]（动效可被下一次点选立即打断，无队列）
```

- 状态机无锁：**连续快速点选 = 每次点选立即生效**，旧动效被打断、新动效接续（不排队、不吞点击——摆弄节奏高于动效完整性）。
- 当前视图为背面时，试穿走同一 `tryOn` 接口，S01 负责当前视图同步换装 + 懒加载；衣柜缩略图**不随旋转变**（保持正面，见 §5.3）。

### 2.3 连衣裙页签联动
- TOP 页签内点选连衣裙：`tryOn('TOP', id)`，S01 隐藏 BTM 渲染（保留状态）；
- BTM 页签在连衣裙穿着期间：**网格可用、点选可换**（状态更新、画面仍被遮蔽），页签顶部一行 Caption 提示"当前被连衣裙遮蔽"（美术圣经 §3.2 Caption 层级，不弹窗）。

## 4. 公式

- **抽屉档位**：`默认档高 = 舞台剩余高 × 45%`，`上拉档 = 舞台剩余高 × 70%`（引美术圣经 §6.1 45%/70% 口径；**基准 = hud-layout.md §4，公式表述与其完全一致**）；上拉手势速度 > 0.5px/ms 时越档吸附，慢速拖拽跟手。
- **网格视口渲染**：`可见卡片数 = ceil(抽屉内容高 / 104) × 4 列 + 上下各 1 行缓冲`；40-50 件量级（D2-02）下单页签最多 ~20 件，**无需虚拟滚动**，仅按视口懒挂载缩略图（滚动外条目占位不加载）。
- **筛选谓词**：`显示集合 = ownedItems(slot) ∧ (activeTag == null ∨ activeTag ∈ item.tags)`——单选标签、OR 语义（v1 无多标签交并需求，认知负担优先）。
- **性能预算**：50 件缩略图总 ≈ 1MB（50 × 20KB），单页签常驻 ≤ 20 张纹理，滚动重挂载无 GC 压力风险；主界面稳态内存预算仍以 paperdoll-render.md §4 为准（缩略图计入 UI 底图份额）。

## 5. 边缘情况（≥3 类）

1. **衣柜 = 已拥有全集**：网格数据经 S04.ownedItems 过滤，**不显示未拥有灰卡**（未拥有内容的浏览与购买全在 S08 商店页完成，职能分区干净）——空槽位页签显示引导卡"这个类别还没有单品，去商店逛逛"（v1 免费无内购语境下为正常引导，非诱导付费）。
2. **发型强制成对**：发型页签的卡片 = 一个发型（前缀对），点选同时设定 HAIR_B+HAIR_F；不存在单独的"后层/前层"页签，杜绝跨发型混搭（paperdoll-render.md §5.2 接口层双保险）。
3. **背面视图下的缩略图**：缩略图固定正面（成本：全量 50 张背面缩略图收益近零；玩家点选后 300ms 内即可在角色台上看到背面效果，符合 P1）。
4. **连衣裙 + BTM 联动遮蔽提示**（§2.3）：提示为非阻塞 Caption，不阻止操作——状态与渲染解耦的交互面表达（对应 paperdoll-render.md §5.1）。
5. **空档首启**：新档默认套装（local-save.md §5.3 同路径）保证 13 槽页签全部非空；卸下按钮在任何页签可用（槽位回空 = BODY 遮蔽形态，未成年向安全，美术圣经 §4.3 L01）。
6. **快速连点/动效打断**：点选立即生效（§2.2 无锁设计）；极端连点（>10 次/秒）下 stats 计数照常累加（真实行为即真实计数，S09 判据不受影响）。
7. **标签与页签组合空集**：某页签 × 某标签筛选结果为空 → 网格区显示"这个风格还没有单品"空态（不回退标签、不隐藏 chips）。

## 8. 验收标准

1. 点选 → 角色画面变化 ≤300ms（P1 红线实测），动效可被下一次点选立即打断，无点击吞没。
2. 连续滑动浏览 + 点选混操作无掉帧（60fps 目标下无可感知卡顿）；视口外缩略图不加载。
3. 8 分组页签覆盖全部 13 槽、组内逐槽可用且含等价点按路径；发型组成对换装正确；跨发型混搭被拒绝且无穿帮画面（GAP-4 一致性验收）。
4. 连衣裙穿着期间 BTM 页签可换、Caption 提示正确；换回分体上装后 BTM 新选择正确显示。
5. 筛选 chips ≤ 8 组（§9.6），单选 OR 语义正确，空集空态文案正确（§5.7）。
6. 角标状态（当前穿着/未拥有不可达）以图标+描边差异承载，色弱可辨（§9.2）；服装名常显或点击即显（§9.5）。
7. 卡片 104×104、目标间距 ≥ 8px、误触摇头反馈 200ms（美术圣经 §6.2/§8.1）。
8. tryOnTotal/tryOnUnique 计数与实际操作一致（S09 联调基准）。
