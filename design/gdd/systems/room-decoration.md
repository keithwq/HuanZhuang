## 1. 概述

第二个表达画布（概念 v1.1 §2.3）：1 房间 × 21 吸附点（美术圣经 §10.5：地面主点位 9 + 顶面次级 5 + 墙面挂点 6 + 地垫位 1）× 首发 30 件学院向家具。交互与衣柜同构——点选即摆、所见即所得（P1），两步流「点家具 → 点点位」因点位选择而天然必要，无拖拽、无旋转（D2-03）。**解锁结构结论：21 点位初始全开放（定稿备案，见 §2.4）**；氛围光 3 档棘轮式点亮（§4.3）。

## 2. 机制

### 2.1 家具抽屉（复用衣柜范式）

- 容器：hud-layout §6 `getDrawer('room')`；两档抽屉、类目页签（L 大件 / M 中件 / S 小件 / W 壁饰 / R 地垫，5 页签 ≤8 组分类，美术圣经 §9.6 红线内）。
- 卡片 = **已拥有家具全集**（D3-05 职能分区承袭：未拥有浏览归商店家具页签，economy §2.1）；点选卡片 → 进入**摆放模式**（不直接落位——与衣柜"点选即穿"的差异源于点位选择，见 §2.2）。

### 2.2 点位吸附交互流

```
[浏览态] ──点家具卡──→ [摆放模式：该件类目兼容的空点位显示星光提示
                        （≤300ms 呼吸出现；占用点位显示当前家具剪影高亮）]
   ↑                        │ 点空点位
   │                        ↓ [落位 ≤300ms 落定反馈（2% 上浮落定，同衣柜家族动效）]
   │                     替换式：目标位已有件 → 旧件即时回库存 + toast「星光衣柜已收回 ×n」
   └──────落位完成即回浏览态────┘

[浏览态] ──点已摆家具──→ [行内确认条「收回？」[收回][取消]]  ← 显式按钮，不依赖手势（§9.3）
                            └ 收回 = setPlacement(anchor, null)，件回抽屉库存
```

- **类目兼容制（本册定稿）**：件可摆进**其类目任一开放点位**（L 件→L-01/02/03；M→M-01~04；S→地面 S-01/02 + 次级 S-T1~5；W→挂点带位；R→R-01）——以美术圣经 §10.5.5「建议点位」为构图参考而非硬限制（美术原文：不构成解锁限制），最大化表达自由（P2）；**例外两条**：`W-06` 窗帘专用位（仅窗帘类，§10.5.3）；次级 S 点位宿主空缺时隐藏、不可摆（§10.5.2）。
- 摆放模式中再点同一件卡片 = 取消摆放模式（无状态残留）；点其他件卡片 = 切换目标件（星光提示刷新）。
- 无拖拽、无长按、无自由移动（D2-03/美术圣经 §6.2 手势纪律）。

### 2.3 次级点位联动（美术圣经 §10.5.2/6 建议采纳）

- 宿主（L/M 大中件）落位 → 其顶面次级点位（S-T1~5）激活可摆；
- 宿主被替换或收回 → **顶面次级件自动随回库存**（不吞资产），toast 与替换收回合并计数；
- 嵌套深度封顶一层：S 件无顶面，不存在二级叠放。

### 2.4 解锁结构结论：**全开放（定稿备案，无待拍板项）**

21 点位初始全部开放。理由：
1. **产品基调冲突**：D3-03 已将回访拉力重排为"每日任务/成就/收集进度"，点位解锁会新增第四条拉力线，与"静态目录、无刻意节奏"的已拍板基调相悖；
2. **双重门槛伤害**：家具获取已由经济曲线（D3-06 集齐 ≈30 天）控制节奏——锁着的点位在多数时段**无件可摆**，空房间期挫败大于期待；
3. **成长感已有载体**：氛围光 3 档节点（§4.3）+ 摆放类成就（economy 冻结值，§2.5）已完整承担"房间在变好"的渐进反馈，无需再叠锁机制；
4. **30 件 vs 21 位的天然取舍**（主理人提示项）：类目兼容制下玩家永远面临"哪件上、哪件收"的取舍表达——这本身就是可玩性，锁会消解它；
5. 12-16 岁认知负担（美术圣经 §9.6）：灰锁点位 + 解锁条件文案是纯阅读成本。
   （若未来内容扩容至多房间/v1.1，再议分批解锁，届时走决策记录通道。）

### 2.5 家具成就数值冻结（economy-acquire §5.8 暂定值收口）

| 条目 | 冻结判据 | 与结构的关系 |
|------|---------|-------------|
| 学院新居（收集类） | `furniturePlacedTotal ≥ 1`（首次落位） | 承 economy §2.2 原口径，确认成立 |
| 星图小屋（收集类） | **已摆点位数 ≥ 11**（联动氛围光第 2 档，见 §4.3） | 修正原"家具拥有 15 件"——判据从"拥有"改为"已摆"：拥有≠布置，摆放才是玩法规语（P2） |
| 满室星辉（收集类，新增第 3 条家具条目，占 economy 21 条清单内份额） | **已摆点位数 ≥ 17**（联动第 3 档） | 与第 3 档氛围光同步达成，成就页 toast 与满室光效同帧发生 |
| 房间的心跳（行为类） | `furniturePlacedTotal ≥ 10`（含替换） | 原口径确认成立 |

### 2.6 stats 计数口径（本册冻结）

`furniturePlacedTotal`：**每次成功落位 +1（含替换落位）；收回（setPlacement null）不计负、不回退**——摆弄自由（试错无惩罚，D1-01）优先于计数纯净性；拥有数判据走 S04.ownedFurniture 另一字段，两口径不混用。

## 4. 公式

- **已摆点位数**：`occupied = count(placement[21键] ≠ null)`；分母固定 21（含次级位——宿主空缺时次级位虽不可摆，仍计入分母，与美术圣经 §10.5.6 "约 5/21、10/21、16/21" 口径一致）。
- **氛围光档位（判定本册定义）**：
  `目标档 = 0 (occupied < 5) | 1 (occupied ≥ 5) | 2 (occupied ≥ 11) | 3 (occupied ≥ 17)`（25%/50%/80% × 21 向上取整）；
  **棘轮规则**：`ambienceLevel = max(档位, 已存档值)`——**只升不降**（搬走家具不熄灯）：①摆弄中反复收放家具不产生画面闪变；②"点亮的星灯不灭"强化建设感心理账（SDT 胜任感，概念 §3.2）；③降档可由玩家自由恢复，无损失。
- **档位切换视觉**：预烘焙光照分层贴图 3 张按档开关（美术圣经 §10.5.6），切换 ≤300ms 淡入一次、非循环动效（D1-11 合规），减敏直切（§9.4）。
- **落位动效**：≤300ms 落定（2% 上浮落定，与换装确认同家族）；星光提示出现 ≤300ms 呼吸，减敏直显。
- **Y 排序**：家具按 base-y 排序（Phaser y-sort，美术圣经 §10.1），地垫 R-01 恒为最底层、墙面挂点恒在墙体层——排序仅地面件参与。

## 5. 边缘情况（≥5 类）

1. **替换动效打断**：替换 = 原子状态操作（旧件回库存 + 新件落位一次落定）；落位动效可被下一点按打断、状态不受影响；**替换连带次级撤回时 toast 合并**（「已收回 ×2」，不逐条弹）。
2. **次级联动链**：替换 L-02 衣柜（柜顶有星植）→ 星植自动回库存 + toast 合并；玩家随后把星植摆上**新**衣柜顶（S-T4）——次级位随宿主重建激活，无残留禁摆态。收回路径同理（§2.3）。
3. **满点位状态**：21 位全满 → 摆放模式下无空位星光 → 顶部 Caption「点位已满，先收回一件试试」（非弹窗、无红光，美术圣经 §9.6）；抽屉浏览不受限，卡片点按仍进摆放模式但立即见空态提示。
4. **模式切换/覆盖层中断**：摆放模式进行中打开商店覆盖层或切到换装模式 → 摆放模式**自动取消**（星光提示隐藏、未落位零残留）；hud 模式切换过渡中（≤300ms）抽屉吸收触控不可点（hud §2.4 口径）。
5. **家具悬空 itemId**（下架防御，v1 无计划）：点位渲染跳过该件显示为空；placement 悬空键保留待版本迁移（local-save §5.5 同口径）；图鉴/商店侧按各自兜底。
6. **首启空房间**：新档 placement 全 null、ambienceLevel=0 → 家具抽屉空态引导卡（指向商店家具页签，D3-05 同款非诱导表达）；无任何家具时摆放模式不可进入。
7. **收回误触**：点已摆家具 → 行内确认条二次点按才执行（§2.2）；确认条 3 秒无操作自动消失（浏览态回归）。
8. **同类目多件竞争同一点位**：A 摆入 M-01 后，B（同类 M 件）摆放模式下 M-01 显示占用剪影不可点——玩家自然读出"先收再换"或直接点选 B 后用替换路径落位（替换式吸附，美术圣经 §10.5.6 规则 2）。

## 8. 验收标准

1. 摆放/收回全路径经 S04.setPlacement，无第二写入路径；21 键名与美术圣经 §10.5 逐一同名同坐标（常量表比对零差异）。
2. 点家具→点位星光提示→点按落位全程 ≤300ms；替换式吸附正确（旧件回库存、次级联动、toast 合并）。
3. 类目兼容制正确：L/M/S/W/R 各类只能在开放点位集内落位；W-06 仅收窗帘；次级位宿主空缺时隐藏。
4. 氛围光：occupied 5/11/17 三档触发正确、棘轮只升不降、切换 ≤300ms 淡入、减敏直切、非循环动效（D1-11 白名单合规）。
5. 家具成就 4 条冻结判据实测达成即触发（学院新居 ≥1 / 星图小屋 ≥11 / 满室星辉 ≥17 / 房间的心跳 ≥10）。
6. 满点位、空房间、模式切换中断、悬空 itemId 四类边界态表现符合 §5.2/5.4/5.6/5.5。
7. Y 排序抽验：任意 9 件以上同屏组合遮挡关系正确（地垫最底、墙面挂件不参与地面排序）；720×1280 单屏无滚动（D2-04）。
8. 家具抽屉与衣柜抽屉交互一致性走查：两档抽屉、页签滑动+点按双路径、104×104 卡片、空态引导卡——同构验收（复用衣柜测试用例改造）。

## 9. 需用户拍板清单
