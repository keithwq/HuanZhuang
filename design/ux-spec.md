## 1. 用户旅程全流程

### 1.0 首启与加载（对应 architecture §3 场景链 BootScene → PreloadScene → StageScene/UiScene）

| 步 | 玩家所见 | 系统动作 | 规格出处 |
|---|---------|---------|---------|
| 1 | 开场插画 + 星尘填充进度条 + 文案「正在整理衣柜…」 | BootScene 载引擎最小集；插画即美术圣经 §7 ③ 加载插画（一图两用，无独立 splash） | 美术圣经 §7 ③、本册 §6 |
| 2 | 进度条持续推进（无数字百分比——进度感知即可，避免卡顿焦虑） | PreloadScene 载：默认套装 13 槽当前视图 + UI 底图，逐件经 texmem 登记 | architecture §3、paperdoll §2 |
| 3 | 插画淡出 → 换装模式主界面（角色着默认套装、抽屉默认档 45%） | load() 读档（有档读档/无档默认，local-save §5.3）；首启当日任务初始化（daily-task §5.4） | hud §2.1/§5.6、daily-task §5.4 |
| 4 | 玩家首次任意触摸（点标签/卡片） | **Web Audio 解锁触发点**：首次 touchstart 解锁音频上下文 → 预留 `audio.lazyLoad('bgm')` 钩子（阮和鸣方案在途，BGM 不阻塞加载链） | 本册 §6.3 |

### 1.1 核心摆弄循环（换装模式 mode=dress，概念 §4 心流路径）

```
点抽屉卡片 ──tryOn ≤300ms 可打断（paperdoll §2.3/§4）──→ 角色即时变装
   ↕ 横向拖拽角色区 或 点「转身」按钮（双路径，paperdoll §2.2）→ 正/背切换 ≤300ms
   ↕ 顶导「造型」→ 造型面板（覆盖层）→ 空位卡 → 命名 → 保存（look-save §2.3）
   ↕ 造型回穿 = 原子全槽 + 单次焕新动效 ≤300ms（look-save §2.5）
```

| 交互点 | 响应红线 | 册节 · 接口 |
|---|---|---|
| 点卡片 / 卸下卡 | ≤300ms 可见变化、无锁无队列 | wardrobe §2.2 · `S01.tryOn/unequip` |
| 旋转（拖拽/按钮） | ≤300ms 剪影过渡；连续触发忽略 | paperdoll §2.2 · `setView` |
| 抽屉上拉/下拉 | 两档 45%/70%，速度吸附 0.5px/ms | wardrobe §4（基准=hud §4） |
| 保存造型 | 面板浮现 ≤300ms；输入框 ≥88px、软键盘上移避让 | look-save §2.3/§5.5 |
| 任务进度推进 | 试穿当帧进度条 +1 | daily-task §2.1 · `bumpStat` 监听 |

### 1.2 三覆盖层页（互斥单层，hud §5.4；互不嵌套、详情一律内嵌展开）

| 页 | 入口 | 核心流 | 册节 · 接口 |
|---|---|---|---|
| 商店 | 标签栏「商店」/ 货币栏点按 | 浏览（服装⇄家具页签、静态目录 D3-03）→ 内嵌详情 → 购入即入柜；已拥有徽章置灰 | economy §2.1 · `spendCoins/addItem` |
| 成就 | 标签栏「成就」 | 三分组清单 → 惰性判定点亮可领取 → 领取入账/入柜 | economy §2.2 · `claimAchievement` |
| 每日任务 | 顶导「任务」+ 角标 | 3 张任务卡（进度条+领取）→ 逐张领取 150 星尘 | daily-task §2.5 · `addCoins('daily_task')` |

- **闭环引导链**（跨页）：商店余额不足 toast「星尘不够啦，去做每日任务吧」→ 无跳转按钮（单层原则）→ 玩家关店 → 顶导任务角标常显承接（daily-task §2.5 验收 §8.8）。

### 1.3 房间模式（mode=room，第二表达画布）

```
点「房间」标签 ──≤300ms 交叉淡切（hud §2.4）──→ 房间舞台 + 家具抽屉
点家具卡 → 摆放模式（空位星光提示 ≤300ms 呼吸）→ 点点位 → 落位 ≤300ms
   ├ 替换式：旧件回库存 + toast 合并（room §2.2/§5.1）
   ├ 点已摆家具 → 行内确认条 [收回]（显式按钮，room §2.2）
   └ 氛围光：occupied ≥5/11/17 三档棘轮点亮（room §4.3）
```

- 进入模式抽屉重置默认档；摆放模式被覆盖层/模式切换自动取消，零残留（room §5.4）。

### 1.4 回访旅程（跨会话）

打开 App → dateKey 惰性翻转（不等人，local-save §2.3）→ 新 3 任务重抽 → 未完成过期不发奖、已领已落账 → 玩家回到 1.1 摆弄循环。

## 2. GAP-4 页签分组方案（定稿 · 可访问性矩阵 C3 挂账项闭环）

### 2.1 分组表（13 槽 → 8 组，达 C3「≤8 组」上限满配）

| # | 组名 | 成员槽位 | 组内规则 | 图标语义（美术圣经 §6.3 直白口径，U4） |
|---|------|---------|---------|--------------------------------------|
| G1 | **发型** | HAIR_B + HAIR_F | 强制成对操作（wardrobe §5.2 不变）；卸下 = 双槽同卸 | 卷发剪影 |
| G2 | **头饰** | HEAD + FACE | 混组浏览、逐槽换装；卸下卡每槽一张 | 贝雷帽（帽子/眼镜同属"头上戴的"低龄直觉） |
| G3 | **上装** | TOP | 单槽组 | 小衬衫 |
| G4 | **下装** | BTM | 单槽组；连衣裙期间遮蔽 Caption（wardrobe §2.3） | 裙摆 |
| G5 | **外套** | OUT | 单槽组 | 小斗篷 |
| G6 | **鞋袜** | LEG | 单槽组（袜先鞋后层内序为渲染规则，非页签规则） | 小皮鞋 |
| G7 | **配饰** | NECK + HAND_L + HAND_R | 混组三槽；卸下卡三张、Caption 标注「项链 / 左手 / 右手」 | 项链 |
| G8 | **光效** | BK + FX | 混组两槽（翅膀光环纱幔光点聚"氛围"一类）；卸下卡两张 | 星翼 |

- BODY 不入页签（不可卸载遮蔽层，美术圣经 §4.3 L01）——13 槽中用户可操作槽 = 12，分入 8 组。
- **组内次序**（网格排序，本册定稿）：当前穿着件置顶钉住 → 系列聚集 → 系列内稀有度升序（便宜在前、贵物渐进，与 economy §4.1 定价梯度同向，收集路径自然可读）。

### 2.2 定稿理由

1. U4（图标直白）：8 组全部是 12-16 岁无需学习的衣着语义（"头上戴的/身上穿的/脚上踏的/氛围光效"），无抽象分类词；
2. C3 满配 8 组而非更少：再压缩（如上下装合并）会让"连衣裙⇄分体"的核心机制藏进混组，换装主玩法的槽位可见性受损（P2 表达即玩法）；
3. 合并只发生在**低频小槽**（HEAD+FACE、NECK+HAND、BK+FX），高频主槽（上装/下装/外套/鞋袜）全部独立成组——高频操作零认知成本；
4. 图标资产量从 13 降至 8（美术圣经 §6.3 图标集工作量同降，GAP-2 资产包同步受益）。

### 2.3 接口注记（供程基岩，经主理人中转）

`onTabChange` 回调参数由槽位代码变为**组 ID（G1~G8）**——冻结接口的语义（页签切换通知）不变，仅参数枚举域收窄；卡片换装仍逐槽走 `tryOn(slot, itemId)`，组概念不进渲染层。S09「试穿类」任务判据不受影响（判据键是行为计数，非页签）。

## 3. 文案语气规范（daily-task §2.2 纪律推广到全局）

### 3.1 全局五条基调（矩阵 C5 Standard 档）

1. **邀请式动词开头**：「试试 / 逛逛 / 收集 / 布置」——玩家永远被邀请、不被指令；
2. **零倒计时话术**：禁「仅限今天 / 错过不再 / 剩 X 小时」（D1-03、D3-03 结构性无此机制，文案同步禁）；
3. **零损失话术**：禁「别错过 / 快领取，否则……」——未完成不作损失感表达（daily-task §2.4）；
4. **零审美指挥**：禁「正确搭配 / 最佳选择」——系统永远不评判玩家审美（概念 P2）；
5. **柔性错误 + 改进行动**：每个报错文案自带一条出路（「星尘不够啦，**去做每日任务吧**」），禁高饱和红闪（矩阵 U3、圣经 §8.1 柔性错误）。

## 5. 首屏加载体验与音频衔接

### 5.1 加载期视觉与反馈

- **一图两用**：开场插画（美术圣经 §7 ③，独立背景场景第 3 张额度）常驻全屏，星尘填充进度条置插画下缘；无独立 splash、无逐项加载日志（认知负担）。
- 进度反馈为**连续填充**（无跳变闪烁，M1 合规）；文案「正在整理衣柜…」Caption 层级，邀请式。
- 加载总时长目标：首启（默认套装 13 槽 @2× + UI 底图）≤ 5s@4G，回访（缓存命中）≤ 1.5s——超时不视为缺陷，进度条持续存在即反馈承诺（矩阵 C4：进度感知优先于速度焦虑）。
- 减敏（M3）：插画淡出与场景切入均降为 ≤100ms 直切。

### 5.2 预载策略衔接（UX 视角，细则归 architecture §6）

- Preload 只载**当前视图**（正面默认）13 槽 + UI 底图；背面视图全部懒加载（paperdoll §2.2，D2-01）——首屏加载承诺与 CAL-04 纹理预算（稳态 ≤45MB）一致。

### 5.3 Web Audio 解锁与 BGM 延迟加载钩子（阮和鸣方案在途，预留接口）

- **解锁触发点**：首次用户触摸（任意 UI 命中）时 unlock 音频上下文——加载期禁止自动出声（浏览器自动播放策略 + 未成年体验）；
- **BGM 延迟加载钩子**：`audio.lazyLoad('bgm')` 于解锁后异步拉取，**不阻塞任何玩法路径**；加载失败静默降级（无声可玩是 Basic 可用线，音频为增强层）；
- 音量/静音设置项已按 D4-01 轻量包展开：入口与交互规格见本册 **§7 设置项**；存档侧 `settings.audioEnabled` 由 audio-plan §7 申报（经主理人转程基岩落 ADR-002 settings 补丁）。

## 6. 验收对账（Phase 5 引用）

1. 用户旅程全流程走查：1.0~1.4 每步响应 ≤300ms 红线实测（§1 各表）；
2. GAP-4 闭环核验：衣柜页签 = 8 组与 §2.1 分组表逐项一致；混组卸下卡逐槽正确；`onTabChange` 参数域收窄已知会程基岩侧（经主理人）；
3. 文案清单对账：全 UI 实现文案与 §3.2 表零漂移（新增项必须先登记）；
4. 可访问性：§4 逐页用例过矩阵 Basic+Standard 全项；
5. 加载体验：5s/1.5s 目标实测、进度条连续性、减敏直切、BGM 钩子可插拔（无音频可完整通关）；
6. 套装完成事件链：系列目录全集上身 → 光晕 + 音效同帧（paperdoll §2.5 判据实测，含连衣裙占位/批量回穿单发/未拥有不触发三用例）；
7. 设置项：音频开关切换即时生效（mute 无需刷新）、二态图形双通道、静音确认无声（§7.3）。

## 7. 设置项（v1.1 增补 · D4-01 边界内，引用 accessibility-matrix Standard 档）

### 7.1 音频开关（v1 唯一设置项）

| 项 | 规格 |
|---|---|
| 入口 | **HUD 顶导功能入口组最右侧**「小喇叭」二态按钮（hud-layout §2.3 同步行） |
| 状态语义 | 开 = 小喇叭 + 两缕星尘音符；关 = 小喇叭 + 柔和斜杠——**图形差异双通道（V4），不裸靠颜色**；icon 语义直白（U4），贴纸感样式（美术圣经 §6.3 家族，默认态极简无角饰） |
| 交互 | 点按切换 `settings.audioEnabled`（audio-plan §7 表：布尔总开关、默认 true、无 null 跟随态）；**即时生效** mute/恢复（音频层监听即生效，无需刷新） |
| 切换反馈 | 关：icon 单帧切换 ≤300ms（M2）+ **不播确认音**（关了还响即矛盾）；开：icon 切换 + 一段短确认音（audio-plan SFX 家族内，证明声音回来了）；减敏（M3）降 ≤100ms 直切 |
| 触控 | ≥44×44（T1，顶导 icon 实做 48×48 源尺寸）、间距 ≥8px（T2）、按钮即点按无手势依赖（T3 天然满足）、落顶导右端 = 拇指可达边缘（T4） |
| 文案 | **零文案**——纯 icon 二态（信息全部由图形承载，不新增 §3.2 清单条目）；无障碍屏幕阅读器场景 v1 不设专门 label（Comprehensive 档范围，不阻塞） |
