# CAL-04 核对单 · 纹理内存预算与 DPR=3 设备策略

> 状态：**核对完成** · 2026-11-21 · 程基岩（engineering-lead）
> 核对对象：美术圣经 v0.5 §5.5（CAL-04 升级项）——稳态 ≤45MB / 旋转峰值 ≤75MB / 房间 ≤60MB / DPR=3 设备策略
> 核对引擎：**按 ADR-001 定稿引擎 Phaser 3（WebGL）实测口径核算**——GPU 纹理内存 = 位图像素 × 4B（RGBA 未压缩，PNG 文件大小不相关，文件预算 ≤150KB 条款不在本单核对范围、维持美术圣经原文）
> 结论速览：**三档预算全部「通过」**，附 2 条美术侧子规格备案（经主理人转林绘澄）+ 3 条调节杠杆（Phase 5 实测漂移超限时启用）

---

## 1. 核对前提（口径声明）

1. **估算口径**：`GPU 内存 ≈ 纹理宽 × 高 × 4B`（Phaser WebGL 上传后为未压缩 RGBA；NPOT 纹理 CLAMP_TO_EDGE 处理无额外 padding）；
2. **bbox 口径**：按美术圣经 §5.4 各槽**最大占画布比例**取部件外接框（最坏情况），实际平均部件小于此——本单结论为**保守下限通过**；
3. **DPR 链**：ADR-003 方案 C——部件/UI @2× 导入、背景类 @1×、渲染上限 min(DPR, 2)；
4. 纹理文件 ≤150KB/80KB 的**磁盘体积**条款与 GPU 内存正交（压缩 PNG 解压后即为全尺寸 RGBA），维持美术圣经原文不动。

## 5. DPR=3 设备策略定稿（CAL-04 第二问）

| 项 | 结论 |
|---|---|
| 渲染后备存储 | `CSS 尺寸 × min(deviceDPR, 2)`——**上限钉死 2×**。DPR=3 帧缓冲 ≈720×~1600 ≈4.6MB（原生 3× 为 ≈33MB，省 ≈19MB） |
| 部件纹理密度 | @2× 导入（= 源稿 1024×2048 尺寸直接发布，美术导出管线零新增步骤） |
| 背景类密度 | @1× 导出（软渐变/暗纹内容，上采样不可感知） |
| 质量代价论证 | DPR=3 设备上部件纹素密度 ≈1.5 设备像素/纹素——扁平手绘风（美术支柱 3）视觉损失不可感知；GDD §4 "逻辑宽×高×DPR²"公式中的 DPR 项由本策略**封顶为 2** |
| 低端机降级档 | ADR-003 §6：Canvas2D 回退或内存压力 → 全 @1× + renderScale 1（30fps 容忍线内） |

**结论：DPR=3 策略「通过并定稿」**——三条预算线在该策略下成立；GDD paperdoll-render §4 的内存公式 DPR 项按本定稿取 min(DPR,2)。

## 6. 美术圣经子规格备案（经主理人转林绘澄，程基岩不直接改美术圣经）

| # | 备案项 | 内容 | 影响章节 |
|---|---|---|---|
| a | 背景类导出密度 | 更衣室/房间背景整图、氛围光分层、大面光效按 **@1×（720 逻辑宽）**导出；部件/UI/图标维持 2× 源稿发布 | §5.5 缩放链补充 |
| b | 背视图紧裁剪 | 背视图 PNG 按**内容紧外接框裁剪**导出（60% 精度件内容本就稀疏，紧裁剪直接兑现内存收益）；偏移量以锚线网格为准由引擎侧 frame 数据复原 | §4.5/§5.5 补充 |
| c | 氛围光分层稀疏化 | 3 张分层贴图只覆盖受影响区域（圆窗光晕/墙面星轨带/顶染带），非全画布复制 | §10.5.6 补充 |

> 三条备案均不改变既有已冻结数值（锚线/层序/点位/预算三值不动），属导出口径细化。

## 7. Phase 5 实测复验口径（验收证据路径）

- 测量方法：Chrome DevTools（iOS Safari 需真机 Web Inspector）+ `TexMemAccountant.report()` 汇总导出；
- 三用例：①极端穿搭稳态（全大件+翅膀+FX）②连续翻转 20 次峰值采样 ③房间 21/21 全满 + 第 3 档氛围光；
- 证据路径：`tests/evidence/texmem-steady.md` / `texmem-flip-peak.md` / `texmem-room-full.md`；
- 漂移处理：实测超预算 10% 内 → 启用 §8 杠杆 1~2；超 10% → 回本单复核 bbox 假设并回报主理人。

## 8. 调节杠杆（按启用优先级）

1. 衣柜缩略图页签常驻 20 → 12 张（缓冲行减半，≈-1.4MB）；
2. FX/BK 槽 @2× → @1.5×（半透明层与剪影层对密度最不敏感，≈-3.9MB）；
3. 氛围光分层稀疏度提高 / 纱幔 @1×（房间档，≈-2MB）；
4.（最后手段）部件全量 @1.5× 中间密度档（≈-11MB 稳态，线稿轻微变虚，需主理人转美术侧视觉评审）。
